# stock-analyst

TW stock dividend tools: buy-in yield calculator, recommended price, stock detail, watchlist. English / 中文.

Live: https://omygod9138.github.io/stock-analyst/

- Single `index.html`, Vue 3 from CDN (no build step).
- Data from [FinMind](https://finmindtrade.com/) API v4 (no key, ~300 requests/hour per visitor IP).
- Settings and watchlist live in the browser's localStorage.
